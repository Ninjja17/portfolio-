# Shibani Pradhan — Portfolio

An award-winning, high-performance personal engineering portfolio built with **Next.js 16 (App Router)**, **TypeScript**, **TailwindCSS**, and **Framer Motion**.

Featuring an interactive 3D flipping card with ASCII lens shader effects, fluid inertial physics scrolling, and a flagship showcase of **SQUARE** (Enterprise Agent Engineering Platform).

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Ninjja17/portfolio-.git
cd portfolio-
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
npm run build
npm run start
```
